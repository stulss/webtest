## 프로젝트 개요

- **과제명**: 나만의 온라인 포트폴리오 완성
- **계획 시간**: 4~5시간
- **목표**: 링크 하나로 나의 장점과 경험을 보여주는 개인 포트폴리오 1페이지 (이력서 양식 복제 금지, 공개 범위는 직접 결정)
- **기술 방식**: 객체지향 MVC 패턴 (Vanilla JS)
  - `index.html` — 루트에 단독 위치
  - `/css` — View 스타일시트
  - `/js/models` — Model 클래스 (데이터/상태)
  - `/js/views` — View 클래스 (DOM 렌더링)
  - `/js/controllers` — Controller 클래스 (이벤트/흐름 제어)
  - `/assets` — 이미지 등 정적 자원
- **디자인 톤**: 미니멀/모던 다크 테마
- **배포**: 미정 — 로컬 완성 우선, 배포는 추후 사용자가 직접 진행
